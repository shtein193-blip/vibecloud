# VibeCloud на телефоне (Xiaomi / любой Android)

Телефон сам становится сервером: бот, Mini App и база работают на нём, HTTPS-адрес для Mini App
даёт бесплатный туннель Cloudflare. Музыка по-прежнему хранится в Telegram, поэтому места почти не нужно
(база — несколько МБ, кэш — до 1 ГБ).

## 1. Установка (один раз, ~20 минут)

1. Поставь **Termux** и **Termux:Boot** из F-Droid (f-droid.org). Версия Termux из Google Play устарела и не работает.
2. Настрой MIUI, чтобы он не убивал сервер:
   - Настройки → Приложения → Termux → **Контроль активности: Нет ограничений**, **Автозапуск: вкл**;
   - то же для Termux:Boot;
   - в списке недавних приложений потяни Termux вниз и закрепи замком 🔒.
3. Открой Termux и скопируй проект на телефон — через git:
   ```bash
   pkg install -y git
   git clone https://github.com/<твой-логин>/<репозиторий>.git vibecloud
   cd vibecloud
   ```
   или распакуй архив: `termux-setup-storage`, затем `cp -r ~/storage/downloads/vibecloud-main ~/vibecloud && cd ~/vibecloud`.
4. Установи всё нужное:
   ```bash
   bash phone/install.sh
   nano .env      # впиши BOT_TOKEN, STORAGE_CHAT_ID, ADMIN_IDS, AI_API_KEY
   ```

## 2. Запуск

```bash
bash phone/start.sh
```

Скрипт поднимет туннель (адрес вида `https://…trycloudflare.com`), запустит бота, сам обновит кнопку меню
в Telegram и будет перезапускать бота, если тот упадёт. После перезагрузки телефона всё стартует само
(Termux:Boot).

## Рядом с другими ботами (например, VibeNews)

VibeCloud не мешает другим проектам в том же Termux:
- у него **своё окружение Python** (`.venv` в папке проекта) — библиотеки VibeNews не обновятся и не сломаются;
- **свой порт** — 8090 (строка `PORT=` в `.env`), чтобы не столкнуться с портом другого проекта;
- **свой туннель** — скрипт останавливает только туннель VibeCloud, чужие `cloudflared` не трогает;
- **свой автозапуск** — `~/.termux/boot/vibecloud.sh` стартует в фоне и не задерживает автозапуск VibeNews;
- остановить только VibeCloud: `bash phone/stop.sh`.

Каждый проект удобно держать в своей сессии Termux: свайп от левого края → «New session».
Телефону хватит ресурсов на оба: вместе это ~200–300 МБ памяти.

Если Telegram у тебя работает только через VPN, держи VPN включённым на весь телефон — тогда ходят и бот,
и туннель. Слушатели Mini App подключаются по своей сети, им VPN не нужен.

## 3. Важно: один токен — один сервер

Telegram отдаёт обновления только одному экземпляру бота. Выбери вариант:

- **Переехать с Render на телефон.** В Render открой сервис → Settings → **Suspend Service**. Запусти бота на
  телефоне с тем же `BOT_TOKEN` и `STORAGE_CHAT_ID`: при первом старте он сам скачает последнюю копию базы
  из канала-хранилища — медиатеки, плейлисты, статусы и топ переедут целиком.
  Вернуться обратно: останови бота на телефоне (Ctrl+C), подожди минуту (он сохранит финальную копию базы), включи Render.
- **Телефон как тестовый стенд.** Создай второго бота в @BotFather и укажи его токен в `.env` на телефоне.
  Для теста подойдёт отдельный канал-хранилище.

## Полезное

- Логи: `tail -f data/vibecloud.log` (при автозапуске) или прямо в окне Termux.
- Обновиться: `git pull` и перезапустить `bash phone/start.sh`.
- Адрес туннеля меняется при каждом запуске — это нормально: кнопка меню обновляется сама, а ссылки
  «поделиться» ведут через бота. Постоянный адрес — именованный туннель Cloudflare (нужен свой домен):
  укажи его в `.env` как `PUBLIC_URL=https://…` и туннель из скрипта не будет запускаться.
- Телефон должен быть в сети. Работа 24/7 расходует батарею, лучше держать его на зарядке.
